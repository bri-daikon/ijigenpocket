# 日替わり記念日イラスト作成手順

このスキルが呼び出された場合、以下の手順を順番に実行すること。

1. **記念日の特定**:
   - 今日の日付（月・日）を確認し、その日が日本では何の記念日か（例：「即席ラーメン記念日」「川柳の日」など）を特定する。

2. **キャラクターの選定とイラストの生成**:
   - **【選定ルール（履歴の確認・均等ローテーション）】**:
     - 単純なランダム抽出だと偏りが発生しやすいため、必ず事前に `y:\ijigenpocket\img\` ディレクトリ内の過去ファイル一覧を確認すること。
     - 直近で使用されたキャラクターは除外・後回しにし、**過去に一度も選ばれていないキャラクター、または最も長期間選ばれていないキャラクターを最優先**でローテーション選定する。
   - `generate_image` ツールを使用し、選んだキャラクターが記念日のテーマを楽しんでいる画像を生成する。
   - **【画像サイズの指定（必須）】**: スマホの待ち受け画面として使えるように、プロンプトには必ず「縦長（9:16 aspect ratio）」および「スマホ壁紙に適した構図（上下に少し余白があるなど）」の指示を含めること。
   - **【参照画像（character_refs）の活用】**: `y:\ijigenpocket\.agents\skills\daily-anniversary-illustration\character_refs\` 内に三面図や設定画像があるキャラクターは、プロンプト作成時の参考にすること。

3. **プロジェクトへのコピー**:
   - `run_command` ツール（PowerShellの `Copy-Item` コマンド等）を使用して、生成した画像を `y:\ijigenpocket\img\` ディレクトリへコピーする。
   - 命名規則の例: `y:\ijigenpocket\img\[キャラクター名（ローマ字）]_YYYYMMDD.png` （例: `uppou_20260903.png`, `dave_20261002.png`）

4. **SNS投稿用テキストの作成**:
   - InstagramやXに投稿するための文章を作成し、`write_to_file` ツールで `y:\ijigenpocket\img\` ディレクトリ内にテキストファイルとして保存する。
   - テキストファイル名の例: `y:\ijigenpocket\img\[キャラクター名（ローマ字）]_YYYYMMDD.txt`
   - **【テキストの必須要素】**:
     - 定型ハッシュタグ: `#今日は何の日 #LINEスタンプ #LINEスタンプ宣伝部 #スタンプ紹介`
     - キャラクターのハッシュタグ: （上記キャラクター一覧に記載のハッシュタグを使用）
     - 記念日のハッシュタグ: `#[今日の記念日名]` （例: `#世界犬の日`）
     - 簡単な小話: 記念日に合わせてキャラクターが何をしているかなど、イラストにまつわる小話や解説を80文字程度で書く。

5. **完了の報告**:
   - 画像とテキストファイルの作成が完了したら、何の記念日をテーマにしたか、およびそれぞれの保存先ファイルパスをユーザーに報告する。
