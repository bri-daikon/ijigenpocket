# Sticker Shelf — ロリポップ！設置版

LINEスタンプ・LINE絵文字・LINE着せかえを検索・分類・編集できる、PHP＋MySQL製の非公開作品管理サイトです。

## 必要環境

- PHP 8.1以上（8.3または8.4推奨）
- PDO MySQL
- MySQL 8系
- HTTPS
- ロリポップ！のライト／スタンダード／ハイスピード／エンタープライズプラン

エコノミープランではMySQLを利用できないため、サーバー保存版は動作しません。

## 設置手順

1. ロリポップのユーザー専用ページで「サーバーの管理・設定 → データベース」を開きます。
2. このサイト専用のMySQLデータベースを1つ作成します。
3. 「PHP設定」で設置先ドメインのPHPを8.3以上にします。
4. このZIPを展開し、中にあるファイルとフォルダを設置先へすべてアップロードします。
5. ブラウザで `https://設置先URL/setup.php` を開きます。
6. データベース画面に表示されたサーバー名・データベース名・ユーザー名・パスワードを入力します。
7. 12文字以上の管理パスワードを設定し、「初期設定を実行」を押します。
8. 「管理画面を開く」からログインします。

初期設定時に、2026年9月1日時点のLINE作品145件を自動登録します。

## 既存サイトの編集内容を引き継ぐ

1. 現在のサイトで「バックアップ」を押し、JSONを保存します。
2. ロリポップ版へログインします。
3. 「読み込み」から保存したJSONを選択します。

同じ作品IDは更新され、手入力で追加した作品もMySQLへ保存されます。

## 主な機能

- 作品の追加・編集・削除
- タイトル・シリーズ・タグ検索
- スタンプ／絵文字／着せかえ切り替え
- カテゴリ絞り込み・並び替え
- LINE STORE作者ページとの同期（スタンプ・絵文字・着せかえ）
- 画像アップロード
- JSONバックアップ・復元
- 管理パスワードによる非公開化
- ログイン試行回数制限、CSRF対策、セッション保護

## セキュリティ上の注意

- `config.php` にはMySQL接続情報が保存されます。ダウンロードしたり公開したりしないでください。
- `.htaccess` を含めてアップロードしてください。FTP画面でドットから始まるファイルを表示する設定が必要な場合があります。
- 管理パスワードとMySQLパスワードは別々のものを使ってください。
- サイトは必ずHTTPSで開いてください。
- 定期的に「バックアップ」からJSONを書き出してください。

## 更新方法

新作がLINE STOREに追加されたら、管理画面の「LINEから同期」を押します。LINE側が一時的に一部の作品を返さない場合でも、既存作品を削除しない設計です。

着せかえは https://store.line.me/themeshop/author/11931075/ja から取得します。LINE STOREに公開された作品だけが同期対象です。
