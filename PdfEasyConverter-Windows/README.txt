セショサポ Windows版 2.0.3

ウィンドウ表示
画面上部の「常に手前に表示」で、他のウィンドウより手前に表示するか切り替えられます。
初期状態はONです。チェック状態は保存され、次回起動時にも引き継がれます。

Ver.2.0.0 の追加機能
画面タイトルを「セショサポ」に変更しました。
中央ペインに「探索者ビューア」「NPCビューア」「卓報告作成」のタブを追加しています。
探索者・NPC情報は .pec ファイルに含めて保存・復元できます。
卓報告作成ではシステム名、シナリオ名、参加者、結果、日付、メモなどから報告文を作成できます。
NPC編集では、ココフォリア出力用の3つの表示設定と自由チャットパレットを設定できます。
SANには0を含む任意の現在値を手動設定できます。NPC駒の正気度ロールは1d100形式で出力し、DBはステータス欄ではなくチャットパレット変数として扱います。

起動方法
1. ZIPを右クリックし「すべて展開」してください。
2. 展開したフォルダーの PdfEasyConverter.exe をダブルクリックします。
3. PDFまたはTXTを読み込んで利用してください。

インストーラーはありません。EXEだけを移動せず、www・DLLなどを含むフォルダー全体を保管してください。起動用ショートカットはEXEに対して作成できます。ローカルディスクへの展開をおすすめします。

必要な環境
Windows 10/11（64ビット x64）、.NET Framework 4.8以降、Microsoft Edge WebView2 Runtime。
作成時のPCには必要な実行環境が入っていることを確認済みです。
他のPCでWebView2がないと表示された場合は、Microsoft公式ページのEvergreen Runtimeをインストールしてください。
https://developer.microsoft.com/microsoft-edge/webview2/
本ビルドはコード署名を付けていません。

ブラウザー版からの引き継ぎ
1. ブラウザー版で、カード一覧上部の「保存」から .pec ファイルを書き出します。
2. Windows版で、その隣にある「読込」から .pec ファイルを開きます。
3. PDFプレビューも必要な場合は元PDFを開き、カード上書きの確認で「キャンセル」を選びます。カードを維持したままPDFを表示できます。
ブラウザーの自動保存領域とWindows版の保存領域は別です。自動でブラウザーの保存データを読み取ることはありません。

保存
「保存」でWindowsの保存先選択画面が開きます。重要な編集データは .pec として保管してください。
編集状態の自動保存先は %LOCALAPPDATA%\IjigenPocket\PdfEasyConverter\WebView2 です。
同じ元ファイルを開くと、前回の編集状態を復元する確認が表示されます。
画面を閉じる際にも現在のカード内容を自動保存します。開いた直後に前回のPDFを自動で開く機能はありません。
自動保存に失敗した場合は警告を一度表示して終了します。大量データや重要な編集内容は、終了前に画面の「保存」から .pec ファイルへ書き出してください。
.pec には編集したカードとふりがな等が含まれますが、元PDF本体は含まれません。

ふりがなの一括編集
「ふりがな」をON → 漢字の語をクリック → 読みを入力 →「同じ表記をすべて変更」。
検索・折りたたみ中も含む、全カードのふりがな付きの語が対象です。語の表記が完全一致する箇所を変更します。
「この箇所だけ」と「元に戻す／やり直す」にも対応しています。

発言者設定
右側の「8. 発言者設定」で名前を追加・編集・並べ替え・削除して保存できます。
各カードでは、保存した名前をプルダウンから選択できます。鉛筆ボタンによる個別の手入力も引き続き利用できます。
発言者の候補は自動保存され、.pec ファイルにも含まれます。

大量カードの軽量表示
301枚以上では、画面付近のカードを最大120枚だけ描画して初回表示と操作を軽くします。
検索・一括選択・保存・しおり・目次ジャンプは、画面外を含む全カードを対象にします。
8000枚を超えるデータでも全カードを保持したまま編集できます。

オフライン対応
PDF.js、Lucide、日本語フォント、ふりがな変換ライブラリと辞書を同梱しています。
アプリ本体のPDF/TXT変換・ふりがな変換にインターネットは不要です。
外部サイトへのリンクやココフォリアの利用にはネット接続が必要です。外部リンクは既定のブラウザーで開きます。
既存のココフォリア連携ブックマークレットは引き続きブラウザー側で利用します。アプリが自動でメッセージを送信する機能はありません。

軽さについて
WebView2 Runtimeを共有して使い、ブラウザー本体や.NET本体を配布物に同梱していません。
HTML版の変換処理・PDF解像度・辞書を維持しています。大量カードでは画面に作る要素を抑え、初回表示とカード操作を軽くしています。
配布容量にはオフライン用辞書とフォントが含まれるため、単体のHTMLより大きくなります。

開発用ファイル
source/Program.cs がWindowsウィンドウと保存処理、www/index.html が実際の画面です。
source/build.ps1 をPowerShellで実行すると、同梱のDLLとWindowsのC#コンパイラでEXEを再ビルドできます。
source/PdfEasyConverter.light.source.html は画面の読みやすいソースです。
