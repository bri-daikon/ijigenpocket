# TRPG Scenario Generator

このツールは、クトゥルフ神話TRPGのシナリオプロットやアイデア（ネタ）から、トレーラー、概要、および詳細なシナリオ本文を自動生成するスクリプトです。生成にあたっては、シナリオ構成担当部門のAI社員（ガクト、ヒカリ、ミヤビ）が協力して議論と執筆を行うプロセスをシミュレートします。

生成されたシナリオは、ローカルに手動インポート用の Markdown ファイルおよび CSV ファイルとして保存されるほか、設定により Notion や Google スプレッドシートへ直接自動書き出しを行うことができます。

---

## 1. セットアップ手順

### 1-1. Python 仮想環境の作成（推奨）
プロジェクトフォルダ内で以下のコマンドを実行し、仮想環境を作成して有効化します。

Windows (PowerShell/コマンドプロンプト):
```bash
翻訳不可：[python -m venv venv]
翻訳不可：[.\venv\Scripts\activate]
```

### 1-2. 依存ライブラリのインストール
以下のコマンドを実行し、必要なライブラリを一括インストールします。

```bash
翻訳不可：[pip install google-genai notion-client gspread oauth2client]
```

---

## 2. 設定手順

`翻訳不可：[config.json]` ファイルを開き、必要な情報を設定します。また、各APIキーは環境変数として設定することも可能です（環境変数が優先されます）。

### 2-1. Gemini API（必須）
Google AI Studio 等から Gemini API キーを取得し、設定します。
* `翻訳不可：[config.json]` 内の `翻訳不可：[gemini_api_key]` に記述する。
* または、環境変数 `翻訳不可：[GEMINI_API_KEY]` を設定する。

### 2-2. Notion 連携設定（任意）
設定すると、作成されたシナリオ全体が自動的に指定したNotionページ配下（またはデータベース内）に新規ページとして書き出されます。
1. Notionのインテグレーションを作成し、APIキー（Internal Integration Token）を取得します。
2. 作成先となる親ページまたはデータベースに対して、インテグレーションのアクセス接続を許可します。
3. `翻訳不可：[config.json]` の `翻訳不可：[notion]` セクションを設定します。
   * `翻訳不可：[api_key]`: Notion APIキー
   * `翻訳不可：[parent_page_id]`: 親ページのID、またはデータベースのID
   （※環境変数 `翻訳不可：[NOTION_API_KEY]` および `翻訳不可：[NOTION_PARENT_PAGE_ID]` でも指定可能です）

### 2-3. Google スプレッドシート連携設定（任意）
設定すると、シナリオのタイトルや推奨人数、ロスト率などの概要スペックがスプレッドシートの末尾行にレコードとして自動追加されます。
1. Google Cloud Console でプロジェクトを作成し、Google Sheets API と Google Drive API を有効化します。
2. サービスアカウントを作成し、JSON形式の秘密鍵キーファイルをダウンロードします。
3. ダウンロードしたJSONファイルを `credentials.json` という名前でこのフォルダ内に配置します。
4. 対象のスプレッドシートを作成し、サービスアカウントのメールアドレスに対して「編集者」権限で共有します。
5. `翻訳不可：[config.json]` の `翻訳不可：[google_sheets]` セクションを設定します。
   * `翻訳不可：[credentials_file]`: 認証JSONファイルのパス（デフォルト: `credentials.json`）
   * `翻訳不可：[spreadsheet_id]`: スプレッドシートのID（URLに含まれる長い文字列）

---

## 3. 使用方法

1. `翻訳不可：[input.txt]` をテキストエディタで開き、TRPGシナリオの元となるアイデアやプロットを記述します。
2. 仮想環境が有効な状態で、スクリプトを実行します。

```bash
翻訳不可：[python scenario_generator.py]
```

---

## 4. 出力ファイル

API連携の設定有無に関わらず、実行完了時に以下のローカルファイルが生成・更新されます。

* **`翻訳不可：[scenario.md]`**: NotionなどのMarkdown対応エディタに直接コピペ・インポートできるシナリオ本文。議論プロセスやトレーラーも含まれます。
* **`翻訳不可：[scenario_data.csv]`**: Googleスプレッドシート等に直接ドラッグ＆ドロップでインポートできるスペックデータ。過去に生成したシナリオ情報が追記されていきます。
