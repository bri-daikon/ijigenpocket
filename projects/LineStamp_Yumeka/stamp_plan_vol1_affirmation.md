# ゆめかちゃん LINEスタンプ企画案：やさしい肯定と励まし（全肯定ゆめかちゃん）

生成用スライス指定：縦5×横4（20種類）を2枚分（合計40個）

## 1枚目（1〜20）：基本の肯定と癒やし
日常的に一番使いやすい、相手を褒めたり労ったりするスタンプ群です。

| 番号 | テキスト | ゆめかちゃんのポーズ・シチュエーション |
| :--- | :--- | :--- |
| 1 | **えらい！** | 目を細めてにっこりとやさしく微笑んでいる。 |
| 2 | **よしよし** | 短い前足を少し上げて、相手の頭をなでるような仕草。 |
| 3 | **がんばったね** | 小さなパステルカラーのお花をくわえて差し出している。 |
| 4 | **おつかれさま** | 温かいミルクが入ったマグカップを両前足で大切そうに抱えている。 |
| 5 | **すごい！** | 大きな紫色の瞳をキラキラさせて、おほしさまのヘアピンも光っている。 |
| 6 | **さすが！** | うんうん、と深く頷きながら、誇らしげな優しい顔。 |
| 7 | **ムリしないでね** | うるうるの瞳で、少し心配そうに上目遣いで見つめている。 |
| 8 | **休もう** | 白くてふわふわの雲の上で、とろけるように寝そべっている。 |
| 9 | **応援してるよ** | お尻をこちらに向けてフリフリし、雲と星の「ゆめのあかし」を見せている。 |

| 11 | **大正解！** | 嬉しそうに短足でピョンと軽く飛び跳ねている。 |
| 12 | **いつでも味方だよ** | 大きな星のクッションをギュッと抱きしめている。 |
| 13 | **はなまる！** | ピンク色のクレヨンをくわえて、空中に大きな丸を描いている。 |
| 14 | **いいと思う！** | 外ハネのボブカットを揺らしながら、元気に同意している。 |
| 15 | **生きててえらい** | 仰向けにごろんと寝転がり、リラックスしきった無防備なポーズ。 |
| 16 | **ゆっくりでいいよ** | ちょこんと座り込んで、のほほんと首をかしげている。 |
| 17 | **100点満点！** | 星型の小さな看板を嬉しそうに見せている。 |
| 18 | **尊い…** | 両前足をほっぺに当てて、うっとりとした表情。 |
| 19 | **完璧です** | ちょこんと前足を揃えて、お上品に軽くお辞儀をしている。（足は4本） |
| 20 | **無理は禁物** | 優しい顔で、前足を小さくバツ（×）の字に交差させている。 |
