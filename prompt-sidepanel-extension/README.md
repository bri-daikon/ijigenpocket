# QuickPrompt SidePanel - 定番プロンプト送信ツール

ChatGPT、Claude、Google Gemini、Copilot などのWebブラウザ入力欄に、よく使う定番プロンプトをワンクリックで素早く挿入・送信できるChromeサイドパネル拡張機能です。

---

## 🛠️ インストール手順（1分で完了）

1. Google Chrome を開きます。
2. アドレスバーに以下を入力して Enter を押します：
   ```
   chrome://extensions/
   ```
3. 画面右上にある **Developer mode（デベロッパー モード）** のスイッチを「ON」にします。
4. 画面左上に出現する **Load unpacked（パッケージ化されていない拡張機能を読み込む）** ボタンをクリックします。
5. フォルダ選択ダイアログで、以下のフォルダを選択します：
   ```
   y:\ijigenpocket\prompt-sidepanel-extension
   ```
6. 拡張機能一覧に **「QuickPrompt SidePanel - 定番プロンプト送信ツール」** が追加されればインストール完了です！

---

## 🚀 使い方

### 1. サイドパネルを開く
* Chromeのツールバーにあるパズルピース型アイコン（拡張機能メニュー）をクリックし、**QuickPrompt** をピン留め（Pin）しておくと便利です。
* アイコンをクリックすると、ブラウザの右側にサイドパネルがスムーズに展開します。

### 2. プロンプトの挿入・送信
ChatGPT や Claude などのAIチャット画面を開いた状態で：
* **「挿入」ボタン**: チャット入力欄にプロンプトのテキストを直接流し込みます。
* **「挿入&送信」ボタン**: 入力欄に流し込んだあと、自動で送信まで実行します。
* **「コピー」ボタン**: クリップボードに一発コピーします（入力欄のないページ等で利用可能）。

### 3. 変数プレースホルダー機能（`{{変数名}}`）
プロンプト内に `{{対象文章}}` や `{{キャラクター名}}` と書いておくと、ボタンを押した際に自動で**入力ポップアップ**が表示され、内容を埋め込んでから挿入・送信できます。

### 4. プリセットとカスタマイズ
* 最初から「文章推敲」「要約」「アイデア出し」「画像生成（Midjourney英語変換）」「LINEスタンプ企画」「コード解説」などの厳選定番プロンプトが登録されています。
* 「＋新規追加」ボタンから、自分好みのプロンプトを自由に追加・編集できます。
* 「★」アイコンでお気に入りに登録すると、常にリストの最上部に固定されます。
* ⚙️ 設定メニューから JSON ファイルへのエクスポート・バックアップも可能です。
