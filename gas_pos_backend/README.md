# Googleスプレッドシート連動 POSレジ・在庫管理システム セットアップガイド

本システムは、ブラウザアプリ（`SpreadsheetPos.html`）とGoogleスプレッドシート（Google Apps Script）を接続して動作します。

---

## 🚀 導入手順（3ステップ）

### ステップ 1: スプレッドシートの作成
1. [Google スプレッドシート](https://sheets.google.com) を新規作成します。
2. スプレッドシートのタイトル（例: `在庫管理・POSレジマスター`）を設定します。

### ステップ 2: Google Apps Script (GAS) の設定
1. メニューバーの **「拡張機能」 > 「Apps Script」** をクリックします。
2. 開いたエディタの `Code.gs` に、本フォルダ内の [`Code.gs`](file:///y:/ijigenpocket/gas_pos_backend/Code.gs) の中身をすべてコピー＆ペーストして保存（Ctrl+S）します。
3. エディタ上部の関数選択で **`initSpreadsheet`** を選択し、**「実行」** をクリックします。
   - ※ 初回のみ権限の承認画面が出ます。「詳細を表示」>「（安全ではないページ）に移動」をクリックして許可してください。
   - これにより、スプレッドシートに `Products`（商品マスター）、`Sales`（売上履歴）、`InventoryLogs`（入出庫履歴）シートが自動生成され、サンプルデータが書き込まれます。

### ステップ 3: ウェブアプリとしてデプロイ
1. 右上の青いボタン **「デプロイ」 > 「新しいデプロイ」** をクリックします。
2. 左側の歯車アイコンをクリックし、**「ウェブアプリ」** を選択します。
3. 設定項目を以下のように指定します:
   - **説明**: `POS Backend v1`
   - **次のユーザーとして実行**: **自分 (your_email@gmail.com)**
   - **アクセスできるユーザー**: **全員 (Anyone)**  ※重要：ブラウザからの通信を許可するため
4. **「デプロイ」** をクリックします。
5. 表示された **「ウェブアプリのURL」** （`https://script.google.com/macros/s/.../exec`）をコピーします。

---

## 💻 アプリ（フロントエンド）での接続

1. `SpreadsheetPos.html` をブラウザで開きます。
2. 右上の **「⚙️ 設定」** ボタンをクリックします。
3. コピーした **ウェブアプリURL** を貼り付け、**「接続テスト & 保存」** をクリックします。
4. 「接続成功」と表示されればセットアップ完了です！
   - スプレッドシートの商品が自動で読み込まれ、レジ打ち・在庫連動が可能になります。

## 📌 シート構成の説明

| シート名 | 用途 | 主な列 |
| :--- | :--- | :--- |
| **`Products`** | 商品マスター & 現在の在庫数 | `code`（コード）, `name`（商品名）, `category`（カテゴリ）, `price`（売価）, `cost`（原価）, `stock`（在庫数）, `minStock`（安全在庫アラート閾値）, `image`（アイコン/画像URL） |
| **`Sales`** | 会計・売上履歴 | `orderId`（注文ID）, `timestamp`（日時）, `itemsJson`（明細JSON）, `totalAmount`（合計額）, `paidAmount`（預かり額）, `changeAmount`（釣銭）, `paymentMethod`（決済方法） |
| **`InventoryLogs`** | すべての入出庫・販売履歴 | `logId`, `timestamp`, `productCode`, `productName`, `changeQty`（変動数）, `stockAfter`（変動後在庫）, `type`（販売/入庫/出庫/棚卸調整） |
