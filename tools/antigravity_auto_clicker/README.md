# Antigravity Auto Clicker

Antigravity IDE上で頻出する各種ボタン（確認モーダルの Submit（送信）、実装計画の Proceed（続行）、チャット欄の送信ボタンなど）を画面認識し、指定されたボタンのみを自動でクリックするデスクトップ支援ツールです。

---

## 🌟 主な機能

- **対象ボタンの個別選択**
  - ツール実行確認の Submit（送信）
  - 実装計画の承認 Proceed（続行）
  - チャット入力欄の Submit（送信） / 送信アイコン
  - 任意の独自ボタン（「＋ 新しいボタンを追加...」から自由に追加可能）
- **安全第一の設計**
  - **非常停止・再開トグルキー**: どの画面を開いていても `翻訳不可：F9` キーを押すだけで瞬時に監視の開始・停止が切り替わります。
  - **連打防止クールダウン**: ボタンを1回クリックした後、指定秒数（標準2.0秒）は待機するため、二重実行を防止します。
  - **自分自身のクリック防止**: 本ツールのウィンドウ内にボタン画像が表示されていてもクリックしません。
- **画面からの切り抜き登録（📷 画面から再登録）**
  - ボタンをマウスで四角く囲むだけで、お使いの環境（テーマカラー、解像度、フォント等）に合わせたテンプレート画像を一瞬で再登録できます。
- **設定の自動保存**
  - チェック状態や待機秒数などは自動で `翻訳不可：settings.json` に保存されます。

---

## 🚀 起動方法

### 方法1: バッチファイルから起動（一番簡単）
フォルダ内の `翻訳不可：run.bat` をダブルクリックするだけです。

### 方法2: コマンドラインから起動
```bash
cd y:\ijigenpocket\tools\antigravity_auto_clicker
python gui_clicker.py
```

## ⚙ パラメータ説明

| 設定項目 | 説明 | おすすめ値 |
|---|---|---|
| **監視間隔** | 画面内を走査する間隔（秒） | `翻訳不可：1.0` 秒 |
| **連打防止待機** | クリック後の待機クールダウン（秒） | `翻訳不可：2.0` 秒 |
| **判定感度** | テンプレート画像との一致度（0.60〜0.98） | `翻訳不可：0.85` 前後 |
| **通知音（Beep）** | クリック成功時に「ピピッ」と音を鳴らす | ON |
| **最前面に固定** | 常に手前にツールウィンドウを表示 | ON |
